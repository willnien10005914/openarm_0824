# DaMiao Motor Control Modes (達妙馬達控制模式)

達妙馬達支援四種不同的控制模式，每一種針對不同的使用情境最佳化。在底層，所有模式最終都會轉換為 FOC (Field Oriented Control) 內迴圈的電流控制。

---

## 1. MIT Mode (阻抗控制模式)
此模式（命名源自 MIT 獵豹機器人）提供阻抗控制，允許同時指定位置、速度、剛性、阻尼與前饋扭矩。這是在機器狗或機械臂中最常使用的彈性控制模式。

*   **Target Position (rad)**: 目標位置 (弧度)
*   **Target Velocity (rad/s)**: 目標速度 (弧度/秒)
*   **Stiffness (Kp)**: 位置增益（剛性），數值範圍通常為 0-500。決定馬達拉向目標位置的力道。
*   **Damping (Kd)**: 速度增益（阻尼），數值範圍通常為 0-5。用來吸收震盪，提供摩擦感。
*   **Feedforward Torque (Nm)**: 前饋扭矩。直接加上去的額外力量（通常用來補償重力）。

**控制原理**：
輸出扭矩 = Kp * (目標位置 - 目前位置) + Kd * (目標速度 - 目前速度) + 前饋扭矩

---

## 2. POS_VEL Mode (位置與速度限制模式)
此模式提供帶有梯形速度曲線的位置控制。馬達會朝著目標位置移動，並自動進行加速與減速，同時將最高速度限制在您指定的範圍內。適合需要平滑移動到定點的場合。

*   **Target Position (rad)**: 目標位置 (弧度)
*   **Velocity Limit (rad/s)**: 移動過程中的最高速度限制 (弧度/秒)

**控制原理**：
內部有一個位置迴圈會根據目標位置產生一個「目標速度」，然後由速度迴圈追蹤這個速度。您設定的 `Velocity Limit` 會用來直接裁切（Clip）位置迴圈輸出的最大速度。

---

## 3. VEL Mode (純速度控制模式)
此模式提供純速度控制。馬達會嘗試維持在您指定的目標速度。正值代表一個方向，負值代表反方向。適合用在輪式機器人或只需要一直轉動的情境。

*   **Target Velocity (rad/s)**: 目標速度 (弧度/秒)

**控制原理**：
直接將速度誤差（目標速度 - 目前速度）透過 PI 控制器轉換為目標電流。

---

## 4. FORCE_POS Mode (力矩限制位置模式)
此模式（力矩-位置混合）在進行位置控制的同時，加入了「最高速度」與「最大力矩比例」的限制。馬達會向目標移動，但如果遇到阻力，輸出的力道不會超過設定的安全上限。非常適合需要安全互動或夾取物品的場合。

*   **Target Position (rad)**: 目標位置 (弧度)
*   **Velocity Limit (rad/s)**: 移動過程中的最高速度限制 (0-100 rad/s)
*   **Torque Limit Ratio**: 額定扭矩的限制比例 (0.0 - 1.0)。例如 0.5 代表最多只出 50% 的最大力氣。

**控制原理**：
與 POS_VEL 類似，先由位置迴圈與速度迴圈計算出需要的電流，但在最後輸出前，會被 `Torque Limit Ratio` 計算出的最大電流/扭矩給裁切（Clip）掉，確保力量不會超標。
